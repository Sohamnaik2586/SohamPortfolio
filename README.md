# Soham Naik - Interactive Developer Portfolio

An interactive developer portfolio engineered with an authentic **GitHub-style cursor code-tile trail**, built-in **"Dev Quest" minigame**, **interactive REST API & Redis cache sandbox**, and **3D mouse-reactive perspective tilt**.

## 🌟 Highlights & Features

1. **GitHub-Style Cursor Code-Tile Trail:**
   - Moves along your cursor path spawning vibrant syntax-colored tiles with code symbols (`.`, `(`, `/`, `-`, `=`, `{`, `}`, `=>`) that fade gracefully into the grid.
2. **Interactive Minigame ("Dev Quest: Production Hero"):**
   - Built directly with HTML5 Canvas & Web Audio API.
   - Catch falling architecture upgrades (`⚡ Redis`, `🛡️ JWT`, `🐳 Docker`, `🧪 xUnit`) while dodging production bugs (`NullReferenceException`, `CORS`, `401 Unauthorized`).
   - Dialogue bubbles introduce Soham's technical accomplishments as you score points.
3. **Live REST API & Redis Cache Simulator:**
   - Test endpoints from the **Lead Management CRM** directly on screen.
   - Compare cold database latency (~184ms) vs Redis cache hits (~12ms).
4. **Interactive 3D C# Hero Card:**
   - Dynamic perspective tilt following mouse coordinates.
   - "Run Program" executes a live compilation simulation with sound & confetti.
5. **Dual Theme Engine & Instant Background Switcher:**
   - Instant toggle between **Obsidian Dark Mode** and **Clean Light Mode**.
   - Built-in **Background Switcher** (Plain Pristine White vs. GitHub Universe Hairline Grid) accessible via navbar button, floating preview pill, or keyboard shortcut `G`.
6. **Full Resume Accuracy:**
   - TechPulse, Revature, and Metainnovix experience.
   - Full Stack Lead Management CRM (with Azure demo credentials `demo@crm.com` / `Demo@123`).
   - Product Inventory Management API.
   - Complete skills matrix, education, and verified certifications (Microsoft, Oracle, NPTEL, Linux, Java).

## 🚀 How to Run & Preview

### Option 1: Direct Browser Launch
Simply double-click [`index.html`](file:///C:/Users/soham/.gemini/antigravity/scratch/portfolio/index.html) to open it in Chrome, Edge, Firefox, or Safari. Everything is self-contained with zero build steps required!

### Option 2: Live Local Server
If you use VS Code, open the folder and use the **"Live Server"** extension or run:
```bash
npx serve .
```
